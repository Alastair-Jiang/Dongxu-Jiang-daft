- **Ridge 天花板已塌**: 修复后 30 股日线 Ridge IC ≈ 0.00(t ≈ 0.01)。

- **最可能的路径**: "有条件 GO → 成本真实化重测"或"NO-GO(交易) → 转型
  研究项目"。这不是坏结果 — 预注册框架的价值正是把这一判断做在 09-30
  之前, 而不是无限投入。
