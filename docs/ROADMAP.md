## 挂起项(明确决策, 数学实现保留不动)

| 事项 | 决策 | 理由 |
|---|---|---|
| `feat/residual-gate-port`(记忆门收缩先验 CP1-CP11) | **挂起, 不移植** | 与 PR #9 的 CDAP logit 空间修复冲突; 信号未验证前不加正则化机制。移植条件: M5 判定为 GO 或"有条件 GO"后按新架构重做移植 |
| top-3 稀疏激活 | 挂起 | 稠密软门控可跑通实验; 稀疏是推理优化, 判定后再说 |
| AHM(硬化引擎) | 挂起(默认关闭) | 推理加速不应先于信号验证 |
| Markowitz 组合优化 | 挂起 | 当前回测用分位数仓位; 判定 GO 后接入 |
