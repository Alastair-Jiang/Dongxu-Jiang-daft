1项目概览 Project Overview

1.1 一句话定义 One-line Definition

DAFT 是一套受 Kimi K3（Moonshot AI，2026 年 7 月，2.8T 参数开源大模型）启发的 PyTorch 量化交易模型。核心创新是让 路由（Router）、记忆（Memory）、特征深度（Depth） 三个信息维度在共享的联合潜空间中互相调制，形成闭环决策引擎，而不是像传统系统那样各自独立运行。

DAFT is a PyTorch quantitative-trading model inspired by Kimi K3 (Moonshot AI, July 2026, a 2.8T-parameter open-source model). Its core innovation is to make three information dimensions — routing, memory, and feature depth — modulate one another in a shared joint latent space, forming a closed-loop decision engine rather than running independently as in conventional systems.

2.2 DAFT 的原创扩展 DAFT's Original Extension

DAFT 做了 K3 没有的一件事：让三个组件互相通信。

DAFT does one thing K3 does not: it makes the three components talk to each other.

  • K3 的局限：MoE routing、KDA forget gate、AttnRes retrieval 是三个孤岛——各自做决策，互不知晓。 K3's limitation: MoE routing, the KDA forget gate, and AttnRes retrieval are three islands — each decides independently, unaware of the others.
  • DAFT 的方案：CDAP（Cross-Dimension Attention Protocol）建立一个 64 维联合潜空间，三个维度的信号投影进去，逐元素乘法融合，再反向投影回各自组件。 DAFT's approach: CDAP establishes a 64-dim joint latent space; the three signals are projected in, fused by element-wise multiplication, and projected back out to each component.
  • AHM（Adaptive Hardening） 进一步把 K3 的静态 3:1 比例替换成数据驱动的动态路由——常见行情走硬化快路径，罕见行情降级回完整 CDAP 计算。 AHM further replaces K3's static 3:1 ratio with data-driven dynamic routing — routine regimes take a hardened fast path; rare regimes fall back to full CDAP computation.

4数据层 Data Layer

4.1 Panel 数据结构 The Panel Data Structure

DAFT 使用三维 Panel 表示市场数据，统一接口解耦数据源和模型。

DAFT represents market data as a three-dimensional Panel, whose uniform interface decouples data sources from the model.

@dataclass
class Panel:
    values: torch.Tensor     # (T, N, F) — 时间 × 资产 × 特征
    mask: torch.Tensor       # (T, N), bool — 可交易性掩码 / tradability mask
    dates: Optional[list]    # T 个日期标签
    asset_ids: Optional[list] # N 个资产标识
    feature_names: Optional[list] # F 个特征名称
    metadata: Optional[dict] # 数据源、频率、生成参数

Mask 的作用：标记停牌、涨跌停板等不可交易状态，在训练和回测中被自动跳过。A 股口径下，mask 由两部分合成：close 有效性（NaN → 停牌/缺失，置 False）与涨跌停检测（_limit_move_mask，见 4.6）。

Mask marks untradable states (suspension, price-limit) so they are automatically skipped in training and backtest. Under A-share conventions the mask is the conjunction of two parts: close validity (NaN → suspended/missing, set False) and price-limit detection (_limit_move_mask, §4.6).

4.2 通道契约 Channel Contract ★

数据源与特征引擎之间存在两种不同的通道布局，历史上被直接混用，导致特征错列：

There are two distinct channel layouts between the data source and the feature engine, historically mixed directly, which caused feature misalignment:

数据源产出 (baostock / yfinance / synthetic):
    ["open", "high", "low", "close", "volume"]          ← OHLCV 布局 / layout

特征引擎需要 (RegimeFeatureExtractor / legacy / Freq):
    ["close", "log_return", "volume", "volume_ratio", "volatility_20"]  ← 基础布局 / base layout

修复方案：新增 src/daft/features/base_features.py 作为唯一转换点，所有特征引擎入口必须首先调用 ensure_base_panel。

The fix adds src/daft/features/base_features.py as the single conversion point; every feature-engine entry must first call ensure_base_panel.

from daft.features.base_features import ensure_base_panel
panel = ensure_base_panel(panel)   # OHLCV → 基础特征布局

转换规则（严格因果 + mask 感知）：

Conversion rules (strictly causal + mask-aware):

  • log_return[t] = log(close[t]) - log(close[t-1])（需 t 与 t-1 均可交易） (requires both t and t-1 tradable)
  • volume_ratio[t] = volume[t] / 滚动20日均量 / 20-day rolling mean volume
  • volatility_20[t] = log_return 的滚动20日标准差 / 20-day rolling std of log_return

若布局既不是 OHLCV 也不是基础布局，则抛出明确错误（失败要响亮，不再静默错列）。

If the layout is neither OHLCV nor base, an explicit error is raised — fail loudly rather than silently misaligning.

4.6 A 股口径升级 A-share Convention Upgrade (v0.3.0)

4.6.1 涨跌停 mask Price-Limit Mask

A 股有涨跌停制度（主板 ±10%，创业板 300/301 与科创板 688 ±20%）。涨停买不进、跌停卖不出，若不处理会把无法成交的"假信号"计入回测收益。baostock_adapter.py 的 _limit_move_mask 在加载数据时把触及涨跌停的交易日 mask 置 False：

A-shares impose daily price limits (main board ±10%; ChiNext 300/301 and STAR 688 ±20%). A limit-up cannot be bought and a limit-down cannot be sold; without handling this, unfillable "phantom signals" leak into backtest P&L. _limit_move_mask in baostock_adapter.py sets the mask to False on any day that hits a limit:

  • 阈值：_is_gem_or_star(ticker) 判断板块，主板 0.095、创业板/科创板 0.195（留 0.5% 余量防前复权误差）。 Threshold: board detection via _is_gem_or_star; main board 0.095, ChiNext/STAR 0.195 (0.5% slack against forward-adjustment error).
  • 判定：当日 close 相对前一交易日 close 的 |涨跌幅| ≥ 阈值 → 该日不可成交。 Rule: |pct change| of close vs prior close ≥ threshold → untradable that day.
  • 边界：首个交易日无前收盘不判（True）；缺失收盘（NaN）的日子保持 True，由 NaN mask 另行置 False，不重复处理。 Edge: first day has no prior close (left True); NaN-close days stay True and are handled separately by the NaN mask.

开关由 config["handle_limit_up_down"]（默认 True）控制。

Controlled by config["handle_limit_up_down"] (default True).

4.6.2 hs300 真实成分股池 hs300 Real Constituent Universe

早期实验用内置 50 只静态样本，既有人工上限（截面太小、权重股同质），也有幸存者偏差。v0.3.0 各运行脚本新增 --universe hs300（默认），按 start 日拉取真实沪深 300 成分股，解除 50 只上限并缓解幸存者偏差：

将 200 维市场状态向量 s_t 映射到 16 维 regime 潜空间 z_t，在潜空间中决定激活哪些专家。

Maps the 200-dim market-state vector s_t to a 16-dim regime latent space z_t, where it decides which experts to activate.

6.1.2 数学公式 Formulation

潜空间投影（低秩瓶颈，过滤噪声）：

Latent projection (low-rank bottleneck, filters noise):

z_t = LayerNorm( W_down · SiLU(W_up · s_t) ) ∈ R^16

其中 W_up 将 200 维升到 64 维，W_down 将 64 维降到 16 维。

W_up lifts 200 → 64 dims; W_down reduces 64 → 16 dims.

温度缩放路由：

Temperature-scaled routing:

p(expert_i | z_t) = exp((W_i^route · z_t + b_i)/τ) / Σ_{j=1..10} exp((W_j^route · z_t + b_j)/τ)
activated = TopK(p, k=3)

Quantile Balancing（零辅助损失负载均衡）：

Quantile Balancing (load balancing with zero auxiliary loss):

b_i ← b_i + η · (1/10 − count_i / Σ_j count_j)

如果某个专家被选得太少，自动加 bias；被选得太多，自动减 bias。

An under-selected expert gains bias; an over-selected expert loses bias.

Noisy Gating（仅训练模式）：

Noisy Gating (train mode only):

p_noisy = softmax( (W_route · z_t + b + ε · softplus(W_noise · z_t)) / τ )

Inspiration: Kimi Delta Attention (KDA) — per-channel forget gate + delta-rule state update.

6.2.1 功能 Role

维护一个固定大小的记忆矩阵 M_t ∈ R^{128×64}，每个时间步通过 delta-rule 在线学习机制更新，不需要存储整个历史序列。

Maintains a fixed-size memory matrix M_t ∈ R^{128×64}, updated each step via a delta-rule online learning mechanism, without storing the full history.

6.2.2 数学公式 Formulation

Per-Channel Forget Gate（低秩瓶颈）：

Per-channel forget gate (low-rank bottleneck):

α_t = σ( exp(A_log) · ( SiTU(W_up · SiTU(W_down · s_t)) + dt_bias ) ) ∈ (0.001, 1)^128

Route-Modulated Forgetting（CDAP 连接：Router → Memory）：

Route-modulated forgetting (CDAP link: Router → Memory):

α'_t = α_t ⊙ σ(W_route · z_t) （路由信号调制遗忘 / routing modulates forgetting）
α''_t = α'_t ⊙ cdap_gate （CDAP 联合空间反馈 / joint-space feedback）

Delta-Rule 状态更新：

Delta-rule state update:

k_t = L2Norm(W_k · s_t) # L2 归一化关键向量（防数值爆炸）
v_t = W_v · s_t # 值向量 / value vector
β_t = σ(W_β · s_t) # 可学习更新步长 ∈ (0, 1)
M_t = M_{t-1} − β_t · k_t ⊗ (M_{t-1} · k_t) + β_t · k_t ⊗ v_t

Memory retrieval:

o_t = M_t^T · q_t, q_t = W_q · s_t
output = RMSNorm( σ(W_out_up · SiTU(W_out_down · s_t)) ⊙ o_t )

6.3 Cross-Dimension Attention Protocol (CDAP) 跨维度注意力协议 ★ 核心方法论创新

6.3.1 设计动机 Motivation

三个信息流——Router 输出 p_t、Memory 状态 M_t、Depth 特征 {h_0, h_1, h_2}——在传统架构中是单向独立的。CDAP 将它们投影到一个共享联合空间，实现双向调制。

Three information streams — Router output p_t, Memory state M_t, Depth features {h_0, h_1, h_2} — are one-way and independent in conventional architectures. CDAP projects them into a shared joint space for bidirectional modulation.

6.3.2 数学公式 Formulation

Step 1 — 三维投影到联合空间：

Step 1 — project the three dimensions into the joint space:

e = f_expert→joint(p_t) ∈ R^64
m = f_memory→joint(flatten(M_t)) ∈ R^64
d = f_depth→joint(concat(h)) ∈ R^64

Step 2 — 逐元素乘法融合 ★ 关键设计决策：

Step 2 — element-wise multiplicative fusion (key design decision):

j = e ⊙ m ⊙ d ∈ R^64

为什么是乘法不是加法？

Why multiplication, not addition?

  • 加法假设三个维度独立贡献 → memory 不确定时仍会加噪声到路由信号。 Addition assumes independent contributions — an uncertain memory would still inject noise into the routing signal.
  • 逐元素乘法 → 任何维度接近零，整条调制通路被静音。 Element-wise multiplication silences the whole modulation path whenever any dimension approaches zero.
  • 强归纳偏置，适合稀疏的、行情依赖的计算。 A strong inductive bias suited to sparse, regime-dependent computation.

Step 3 — 反向投影（Joint → 各组件）：

Step 3 — back-projection (joint → each component):

方向 Direction公式 Formula效果 Effect
→ Routerp'_t = softmax(log p_t + δ · W_router_out · j)记忆+深度修正路由偏好（logit 空间）
→ Memoryg_t = σ(W_memory_out · j) ∈ (0,1)^128额外遗忘门调制
→ Depthw_t = softmax(W_depth_out · j) ∈ Δ²跨层特征检索权重
路由调制在 logit 空间进行（softmax(log p + δ·bias)），保证零调制（δ=0 或 j=0）时严格无扰动——旧实现直接在概率空间加偏置，初始化即扭曲路由。 Routing modulation happens in logit space (softmax(log p + δ·bias)), so zero modulation (δ=0 or j=0) is strictly non-perturbing — the old implementation added bias in probability space, distorting routing at initialization.

Step 4 — 融合输出：

Step 4 — fused output:

h_fused = Σ_{k=0}^{2} w_t^(k) · h_k

CDAP Scales（可学习的三维调制强度）：

CDAP scales (learnable per-dimension modulation strengths):

expert_bias_scale   — 记忆+深度对路由的调制强度 / memory+depth → routing
memory_gate_scale   — 路由+深度对记忆的调制强度 / routing+depth → memory
depth_weight_scale  — 路由+记忆对深度的调制强度 / routing+memory → depth

三个 scale 初始化为 0（zero-init），训练中逐步放开。

The three scales are zero-initialized and gradually released during training.

6.4 Adaptive Hardening Mechanism (AHM) 自适应硬化机制 ★ 研究性，默认禁用

6.4.1 设计动机 Motivation

Kimi K3 使用静态的 3:1 比例。DAFT 的 AHM 从数据中学习快/慢路径比例，而非硬编码：

Kimi K3 uses a static 3:1 ratio. DAFT's AHM learns the fast/slow path ratio from data instead of hard-coding it:

低波动趋势市 → 大部分时间很常规 → 应该 ~90% 走快路径
高波动事件市 → 大部分时间很反常 → 应该 ~10% 走快路径

6.4.2 四大机制 Four Mechanisms

  1. Pattern Counter（模式计数） — pattern = discretize_pattern(routing_probs)（Top-3 专家索引排序），pattern_counter[(regime_id, pattern)] += 1。 Counts (regime, top-3 pattern) co-occurrences.
  2. Cache Builder（缓存构建） — 硬化条件 count(key) ≥ θ_harden AND confidence > ρ_min → 缓存该 (regime, pattern) 的三维调制向量。 Caches the modulation vector once a pattern is seen enough and confidently.
  3. Entropy Guard（熵守卫） — if H(p_recent) > λ_entropy × H_baseline: degrade_to_full_exploration()。 Falls back to full exploration when recent routing entropy spikes.
  4. Staleness Eviction（过期驱逐） — 长时间未命中 + 命中次数 < 阈值的缓存项 → 清除。 Evicts stale, rarely-hit cache entries.

6.4.3 当前状态 Current Status

AHM 为研究性实现，默认禁用。ExpertEnsemble 的 use_hardening 参数默认 False。硬化快路径的完整接线（detect_regime_shift、evict 在生产管线中的调用）尚未完成，见附录 C 待办。 AHM is a research-grade implementation, disabled by default; use_hardening defaults to False. Full wiring of the hardened fast path into the production pipeline is unfinished (§Appendix C).

11.3 交易制度约束 Trading-Regime Constraints (v0.3.0)

A 股的两条硬约束在回测层落实：

Two hard A-share constraints are enforced in the backtest layer:

  1. T+1：日线收盘-收盘持仓结构下，t 日收盘建仓的头寸最早于 t+1 日收盘平仓（持有满 1 日），T+1 约束结构性满足。 Under close-to-close daily holding, a position opened at t's close can be closed at t+1's close at the earliest — T+1 is structurally satisfied.
  2. 停牌/涨跌停成交约束：respect_mask_no_trade=True（默认）时，mask=False 的交易日（停牌或触及涨跌停）既不能开仓也不能平仓——该资产持仓维持昨收、不计换手与成本。信号选择阶段已把 masked 资产排除在建仓之外；此处补齐"已持仓资产在跌停日卖不掉"这一半。 With respect_mask_no_trade=True (default), a masked day (suspension or price-limit) forbids both opening and closing — the position is held at yesterday's close with no turnover or cost. Signal selection already excludes masked assets from new positions; this closes the other half ("held asset can't be sold on a limit-down day").

调仓频率（v0.3.0 新增）：rebalance_freq 控制每 N 根 bar 才换一次仓，其间持仓不变、成本只在换仓日计提。实验 EXP-20260816-08 显示降频（freq=5）比信号平滑更有效地压换手且不衰减 IC。

Rebalance frequency (v0.3.0): rebalance_freq rebalances once every N bars; positions are otherwise held and cost accrues only on rebalance days. EXP-20260816-08 shows down-sampling (freq=5) cuts turnover more effectively than smoothing, without decaying IC.

信号平滑：signal_smoothing=λ 用因果 EMA 平滑信号（s'_t = (1-λ)·s_t + λ·s'_{t-1}），降换手不引入 look-ahead；λ=0 等价原信号。

Signal smoothing: signal_smoothing=λ applies a causal EMA (s'_t = (1-λ)·s_t + λ·s'_{t-1}), reducing turnover without look-ahead; λ=0 is the identity.

  1. 修复通道契约与对齐后，30 股 Ridge IC 从 0.029 塌到 ≈0——旧"弱信号"是错列特征产物；且 30 股无信号本身是股票池效应（权重股同质 + 截面太小）。 After the channel-contract and alignment fix, 30-name Ridge IC collapsed from 0.029 to ≈0 — the old "weak signal" was a misalignment artifact; and the 30-name null result is itself a universe-size effect (homogeneous heavy-weights + tiny cross-section).
  2. 100 股 hs300 真实成分 + 涨跌停 mask 下，Ridge IC=0.048 / t=5.19 / 净 Sharpe=+0.53 — 基线即达预注册 GO 线。 Under 100-name hs300 constituents + price-limit mask, Ridge IC 0.048 / t 5.19 / net Sharpe +0.53 — the baseline already hits the pre-registered GO line.

C已知问题和 TODO Appendix C. Known Issues & TODO

C.1 已知结构性问题 Known Structural Issues

  1. 路由最大熵 — routing entropy ratio 接近理论最大值 ln(10) ≈ 2.303，10 个专家几乎均匀激活，MoE 退化为普通 ensemble。可能的解决方向：降低 Top-K、添加熵正则、在真实行情数据上测试、curriculum learning 降温度。 Routing entropy ratio nears the theoretical maximum ln(10) ≈ 2.303 — the 10 experts activate almost uniformly and the MoE degenerates into an ordinary ensemble.
  2. top-3 稀疏未真正落实（挂起） — 专家池为稠密软门控（所有专家都计算，软概率加权融合），"Top-K 稀疏"目前只是声明。决策：挂起，稠密软门控可跑通实验，稀疏是推理优化，判定后再决定。 The expert pool is dense soft-gating; "Top-K sparsity" is a claim only. Decision: deferred — dense soft-gating runs the experiments; sparsity is an inference optimization to revisit after the verdict.
  3. AHM 未接线（挂起，默认禁用） — detect_regime_shift / evict 在生产管线中的调用未完成。决策：挂起，推理加速不应先于信号验证。 AHM is not wired into the production pipeline. Decision: deferred — inference speedup should not precede signal validation.
  4. legacy 因子 / FFT 未接入 — 35 个 legacy 因子和 FFT 频域特征是独立模块，不参与训练/评估。需接入或明确其定位。 35 legacy factors and FFT features are standalone modules, unused in training/eval.
  5. residual-gate-port 分支挂起 — feat/residual-gate-port（记忆门收缩先验 CP1-CP11）的数学推理部分与 v0.3.0 CDAP logit 空间修复冲突。决策：挂起，不移植，数学实现保留不动；移植条件是 M5 判定为 GO 或有条件 GO 后按新架构重做。 The feat/residual-gate-port branch (memory-gate shrinkage prior CP1–CP11) conflicts with the v0.3.0 CDAP logit-space fix. Decision: deferred, not ported; port only after an M5 GO / conditional-GO verdict, under the new architecture.
