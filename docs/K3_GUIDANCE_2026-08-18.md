## 2. 推理公式链（非具体框架）

> 目的：给 K3 一张"从数据到信号的完整公式依赖图"，审阅时按节点核对
> 数学语义与实现漂移。每个节点列出关键公式形态、不变量与已知问题编号。

### 2.1 输入与特征层

```
Panel(T, N, 5) OHLCV + mask(T,N)
  └─ ensure_base_panel（唯一通道契约转换点）
       close, log_return(因果·mask感知), volume, volume_ratio, volatility_20
  └─ RegimeFeatureExtractor：6 组特征拼接 → s_t ∈ R^200
       g1 价格动态 / g2 量能 / g3 波动结构 / g4 微观结构 / g5 截面 / g6 动量
  └─ 标准化：(s − μ_train)/σ_train，clip ±10    [问题 A2：train-only 需贯穿到底]
```

- 不变量：log_return[t] 依赖 t 与 t−1 均可交易；mask 单元被置零；窗口类特征严格因果。
- 已知漂移：维度填充重复（A5）；窗口缩放 `lookback_scale`（周线 0.2）在契约中已参数化。

### 2.2 路由（RegimeRouter，Stable LatentMoE 移植）

```
z_t = LayerNorm(W_up · SiTU(W_down · s_t))           潜空间 R^16
logits = W_route · z_t + expert_bias(quantile balance 缓存 buffer)
p = softmax(logits / T)  [+ 训练期高斯探索噪声]
topk(p, 3) → 计算后当前未使用（A7）
```

- 不变量：expert_bias 初始为 0 ⇒ 零偏置严格无扰动；inference 温度 0.1。
- 关键历史修复：logit 空间 CDAP（δ=0 ⇒ p'=p 严格成立）；负载均衡 KL 替代互相抵消的熵正则对（塌缩根因，方案 A 已修）。

### 2.3 记忆（KDAMarketMemory，KDA 移植）

```
遗忘门 α = lb + (1−lb)·σ(exp(A_log)·(f(s_t)+dt_bias))      [safe gate，下界 lb=0.001]
       α ← α · σ(W_route_mod · z_t)                        [CDAP: Router→Memory]
       α ← α · cdap_gate                                   [CDAP: Joint→Memory]
β = σ(w_β · s_t) ∈ (0,1)
M ← α⊙M − β·k⊗(Mk) + β·k⊗v                                [delta rule, O(d_k·d_v)]
o = RMSNorm( (Mᵀq) · outgate )
```

- 不变量：α ∈ (lb, 1)；k 经 L2 归一化；无 KV cache、状态定长 128×64。
- 已知问题：批内行语义（A3）；消融显示"记忆关闭最稳、全正"——该结论在 A3 修复前应视为**条件性结论**。

### 2.4 跨维调制（CDAP，原创组件）

```
e = E(p)   m = M̄(d_k 池化)→E_m   d = E_d([L0;L1;L2])
j = e ⊙ m ⊙ d ∈ R^64                                       [联合空间·逐元素乘]
p' = softmax(log p + δ · tanh(s_e) · W_e · j)               [logit 空间反向投影]
g  = σ(tanh(s_m) · W_m · j)                                 [记忆门调制]
w  = softmax(tanh(s_d) · W_d · j)                           [深度权重]
fused = Σ_k w_k · L_k
```

- 不变量：δ=0 或 scale=0 ⇒ p'≡p、g≡0.5、w≡均匀（零初始化 scale ⇒ 启动严格无扰动）。
- 已知问题：调制信号注入交易信号的方式（A6）。

### 2.5 融合与信号

```
signal = Σ_i p'_i · y_i(s_t) + 0.1 · mean(fused + retrieved)   [A6：hack 待替换]
y_i = SiTU(head_i(backbone_i(s_t))) ∈ (−1,1)
```

### 2.6 训练目标（分阶段）

```
Stage1: 各专家独立 loss（方向加权 MSE / IC / 波动 MSE / BCE），冻结前定形
Stage2: L = Σ_i routing_mean_i · loss_i + λ_KL · Σ_i (1/E)·log((1/E)/frac_i)
        （真负载均衡 KL，frac = routing_probs.mean(0)；温度 1.0→0.5；δ=0.1）
Stage3: 全参解冻，η=1e-5，专家 ×0.1，δ=1.0，温度 0.1
```

- 已知结构性弱点（K3 评审已指出、方案 A 只解决了一半）：`loss_i` 是批级标量，
  路由梯度仍只学"群体平均偏好"，**实例级专业化目标从未真正实现**——这是
  研究归档里"E1 路由选错专家"的数学根源，若重开研究线应作为第一优先假设。

### 2.7 评估与回测

```
IC：逐时步截面 Spearman rank IC（k→k+1 对齐）；ICIR = mean/std；t = mean·√T/std
回测：quantile 选股(top 20%, 多空) → 等权/z分数加权 → 双边成本 = Σ|Δw|·bps
      Sharpe 年化 252；MaxDD 净值百分比；真实仓位换手
```

- 已知问题：口径不对称（A4）、成本模型（A8）。
