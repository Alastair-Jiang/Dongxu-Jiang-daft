## 2. v1.0.0 Go/No-Go 预注册(2026-08-09 定稿)

### 背景

Kimi K3 评审(2026-08-09)指出:DAFT 的核心风险不是架构细节,而是**经济可行性天花板**——日频 A 股 + 手工因子 + <500K 参数,样本外净期望可能本来就是零。Ridge baseline 的 IC≈0.03、t≈1.9 暗示这条线就在附近。

### 判定标准(预注册,不再更改)

| 条件 | 判定 | 行动 |
|---|---|---|
| 最优 DAFT 变体 OOS IC ≥ 0.04 且 t ≥ 2.0 | **GO** | 继续 v1.0.0:扩股票池、组合优化、分钟级 |
| 0.02 ≤ IC < 0.04,或 t 在 [1.6, 2.0) | **有条件 GO** | 先做成本真实性(T+1/涨跌停)+ 换手控制,重测 |
| IC < 0.02,或最优变体仍打不过 Ridge | **NO-GO(架构)** | 转型:DAFT 作为"LLM 架构金融化改造"研究项目(论文/比赛/课程),停止交易系统投入 |
| 任意变体净 Sharpe < 0 且原因不可归因于成本 | **NO-GO(交易)** | 同上,且回测框架需先审查 |

### 判定时间

**2026-09-30 前**完成全部判定实验(30 股、同口径、多 baseline、含修复后重跑)。

### 判定实验清单(按序)

| # | 实验 | 目的 |
|---|---|---|
| 1 | Ridge 30 股 OOS(已有,重跑确认) | 基线天花板 |
| 2 | DAFT 30 股 OOS(safe gate 修复后) | 记忆是否真的有用 |
| 3 | DAFT + 信号平滑(λ=0.3/0.5) | 换手是否可压 |
| 4 | DAFT no-cdap / no-memory 消融 | 组件贡献归因 |
| 5 | DAFT 路由稀疏化后重训(per-sample 熵惩罚) | 路由是否真的学出偏好 |
| 6 | 全部同口径对比表 | 预注册判定 |
