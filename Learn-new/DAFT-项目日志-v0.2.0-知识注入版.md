## 第一部分:项目进度(一分钟看懂)

### 1.1 项目是什么

DAFT = 一套受 **Kimi K3**(2026 年 7 月,月之暗面,2.8 万亿参数开源大模型)启发的量化交易模型。核心创意:把 K3 中三个互不相干的架构组件——专家路由 (Stable LatentMoE)、Delta 注意力记忆 (KDA)、跨层注意力残差 (AttnRes)——改造到金融时间序列上,并让三者**双向调制、互相影响**。

一句话比喻:**传统量化模型是三个各干各的部门(情报部判断市场状态、档案室查历史、分析师挑信号);DAFT 让这三个部门开联席会议,互相纠正。** 这就是 CDAP(交叉维度注意力协议)的直觉。

### 1.2 本期完成(v0.2.0,2026-08-06/07)

| 模块 | 说明 | 状态 |
|---|---|---|
| Stage 1 专家训练 | 8 个专家(趋势/反转/波动/事件×2)各自收敛 | ✅ |

### 1.3 实验证据(v0.2.0 QUICK 配置,50 股×300 天合成数据)

```
Stage 1: 8/8 专家收敛(65.7s)
Stage 2: val_IC +0.0446 → +0.0612(155.3s)
Stage 3: val_IC 峰值 +0.1079(67.6s)
回测:   IC +0.0203, Sharpe -1.79(合成数据+成本,预期内为负)
```

**读法**:验证 IC 一路上升(0.045→0.061→0.108)说明"路由+记忆+CDAP"联合训练确实在学东西——这是本期最有力的正面证据。负 Sharpe 是"合成数据信噪比太低 + 成本模型 + 样本内评估"的结果,既不能证明策略有效,也不能证明架构失败,方法论完善前不作结论。

### 1.4 当前最大风险(必须知道)

1. **回测是样本内的**——用整个数据集(含训练段)评估,不是严格样本外。真实评价必须 train/val/test 三段切分
2. **特征标准化有 look-ahead 风险**——归一化参数用全量数据算,泄漏了未来信息(真实数据上是问题)
3. **消融实验全空**——没有任何证据证明 CDAP/AHM 比"三个独立模块"强,这是论文级项目的生死线

### 2.1 计算机/深度学习部分

#### ① Mixture of Experts(MoE,专家混合)

**项目对应**:RegimeRouter(8 专家,Top-3 激活)

**要懂什么**:MoE 的思想是"不训练一个大而全的模型,而是训练很多小专家 + 一个路由器"。每次输入只激活少数几个专家(Top-K),省算力、每个专家可以专精一个子领域。K3 用 896 个专家、每次激活 16 个;DAFT 缩到 8 个、激活 3 个。

**关键前沿**:2025-2026 年 MoE 的核心难点从"路由怎么学"转向"路由怎么稳"——K3 的 Stable LatentMoE 用**潜空间路由**(先压缩到 16 维再做决策)+ **分位数平衡**(免辅助损失)解决专家坍缩问题。

**必读**:
- Time-MoE(首个时序 MoE 基础模型,你的直接对标):https://arxiv.org/abs/2405.16073
- Kimi K3 Technical Report(发布后搜索 "Kimi K3 technical report")
- **扩展阅读**(理解 MoE 为什么有效,经典但重要):"Switch Transformers"(Google,2021):https://arxiv.org/abs/2101.03961

#### ② Delta 注意力(KDA,线性注意力的一种)

**项目对应**:KDAMarketMemory

**要懂什么**:传统 Transformer 的注意力要存全部历史(KV cache),随序列变长而变贵。KDA 改用**状态矩阵 + δ 规则**:每次来一个新数据点,就用"在线梯度下降"更新一个固定大小的记忆矩阵,查询时 O(1) 取结果,不存历史。对金融的意义:记忆大小固定(128×64),与"看了多少天数据"无关——天然适合长历史。

**关键公式直觉**(不用背,理解即可):
```
M ← α·M - β·k⊗(M·k) + β·k⊗v
    遗忘    消除旧关联    写入新信息
```

**必读**:
- KDA(你记忆组件的直接来源):https://arxiv.org/abs/2510.26692
- xLSTM(线性记忆的另一条路线,你的对比对象):https://arxiv.org/abs/2405.04517
- **扩展阅读**(理解"状态空间模型"家族):Mamba(2024):https://arxiv.org/abs/2312.00752

#### ③ 线性注意力与"线性模型悖论"

**项目对应**:你的消融实验必须包含的 baseline

**要懂什么**:2023 年一篇著名论文(LTSF-Linear)发现:在时序预测上,一个**纯线性层经常打败复杂 Transformer**——不是因为 Transformer 笨,而是时序信号可能本身就是线性可分的,复杂模型只是过拟合噪声。这对你的意义:**你必须证明 DAFT 的复杂度换来了真收益**,否则审稿人/面试官会直接用"线性 baseline 打平了你"来否定。

**必读(本项目最重要的"防坑"论文)**:
- LTSF-Linear(AAAI 2023):https://arxiv.org/abs/2205.13504
- PatchTST(你的 transformer 对比对象):https://arxiv.org/abs/2211.14730
- iTransformer(另一条 transformer 路线):https://arxiv.org/abs/2310.06625

#### ④ 训练技巧(你项目里用到的,要知道为什么)

| 技巧 | 项目位置 | 为什么 |
|---|---|---|
| 温度退火 1.0→0.1 | Stage 2 | 先软路由(什么都试),再硬路由(收敛到偏好)——类似模拟退火 |
| 熵正则 | Stage 2 | 防止路由器"永远只选 1 个专家"(坍缩),惩罚极端分布 |
| 分位数平衡 | Router | 免辅助损失的负载均衡,防止某专家饿死 |
| 低学习率联合微调 | Stage 3 | 防灾难性遗忘——大改动会毁掉 Stage 1 学好的专家 |
| 记忆 detach | Stage 2/3 | 切断跨 batch 梯度,防止 BPTT 爆炸 |

### 2.2 数学部分

#### ⑤ 潜空间(latent space)与瓶颈

**项目对应**:Router 的 200→16 维压缩;CDAP 的 64 维联合空间

**要懂什么**:高维数据(200 维市场状态)往往被少数几个"隐藏变量"驱动(市场就几个 regime:牛/熊/震荡)。潜空间 = 把这些隐藏变量显式建模。压缩(200→16)不是丢信息,而是**强制模型找到最重要的 16 个方向**——这就是为什么 K3 的 Stable LatentMoE 要在潜空间路由而不是原始空间路由。

**扩展阅读**:自动编码器的经典论文(理解"压缩=找结构"):https://arxiv.org/abs/1312.6114

#### ⑥ 马尔可夫链与 HMM(你合成数据的地基)

**项目对应**:SyntheticDataGenerator 的三状态 regime 生成

**要懂什么**:你的合成数据用"三状态马尔可夫链"(牛/熊/震荡,95% 概率停留)生成——这是金融 regime 建模最经典的假设。**注意**:合成数据的 regime 是"已知答案"(ground truth),模型在真实数据上没有这个答案,要靠自己学——所以合成数据结果天然偏乐观,这是你理解实验结果时必须记住的偏置。

#### ⑦ Ledoit-Wolf 收缩(组合优化的数学)

**项目对应**:MarkowitzOptimizer

**要懂什么**:Markowitz 均值-方差优化需要协方差矩阵,但股票多、历史短时,样本协方差噪声极大(病态)。Ledoit-Wolf 的直觉:**把样本协方差向一个"结构化的简单目标"(如常数相关矩阵)收缩**,用偏差换方差——这是高维金融估计的标配。你项目里是纯 PyTorch 闭式实现,没有依赖外部求解器,这点做得专业。

**扩展阅读**:原文(Ledoit & Wolf,2004):https://www.sciencedirect.com/science/article/pii/S0304407603002334

#### ⑧ 信息系数 IC(统计概念,整个项目的地基)

**项目对应**:所有验证指标

**要懂什么**:IC = 预测值与实际收益的秩相关系数(Spearman),衡量"预测排序能力"。IC=0.05 以上算可用,0.1 以上算优秀(学术口径)。你的 Stage 3 达到 0.108(合成数据上)——**注意**:合成数据的 IC 天然偏高,真实 A 股 IC 0.03-0.05 已属难得。理解这个差距,是你读自己实验结果的第一课。

### 2.3 经济学/金融部分

#### ⑨ 有效市场假说(EMH)——为什么预测收益那么难

**要懂什么**:EMH 说"价格已反映所有公开信息",所以未来收益基本不可预测(随机游走)。学术界共识:**短周期(分钟/日内)预测性极弱且被交易成本吞噬;长周期(月/年)有微弱可预测性(动量、价值因子)**。你的项目瞄准分钟级——这是最难、成本最重的赛道,需要清醒认识难度。

**必读**:
- Fama(1970)EMH 经典论文:https://www.jstor.org/stable/2325486(读摘要即可)
- **更实用**:López de Prado《Advances in Financial Machine Learning》——防数据泄露、样本外验证的圣经:https://www.wiley.com/en-us/Advances+in+Financial+Machine+Learning-p-9781119482086

#### ⑩ 交易成本与市场微观结构(分钟级策略的生死线)

**要懂什么**:A 股实际交易成本 = 佣金(约 2-3bp)+ 印花税(卖出 5bp)+ 滑点(2-5bp)+ 冲击成本(大单)。**分钟级策略的 Alpha 大头会被成本吃掉**——这是"回测 Sharpe 3.0、实盘亏钱"的头号原因。你的回测引擎已建模双边成本+滑点(5bp+1bp),这是加分项,但真实市场还要考虑涨跌停(无法成交)、T+1(当日不能卖)。

**必读**:市场微观结构经典入门:
- Hasbrouck《Market Microstructure》(书,搜索可得)
- 中文快速入门:搜索"交易成本 量化 滑点 冲击成本"综述文章即可

#### ⑪ 因子投资(多因子模型的现代形态)

**要懂什么**:你的 200 维特征引擎本质上是"因子库"——动量、波动率、量能、横截面排名,全是学术界验证过的因子家族。现代因子研究的核心方法论:**IC 检验(预测力)→ 分组回测(单调性)→ 换手与容量(可交易性)**。你的项目已经天然对齐这套方法论(特征=因子,IC=检验,回测=交易性)。

**必读**:
- Fama-French 三因子(1993,现代因子投资起点):https://pages.stern.nyu.edu/~ehabers/FF_JFE1993.pdf
- **扩展**:Oxford 2026 金融时序大 benchmark(你的回测/对比框架):https://arxiv.org/abs/2603.01820

#### ⑫ regime 切换(为什么"市场状态"建模有价值)

**要懂什么**:金融市场的核心事实是**状态会变**——牛市(趋势强、波动低)、熊市(趋势下、波动高)、震荡(均值回归)。单一模型很难同时适应所有状态,这就是"专家 + 路由器"思想的金融依据:每个专家专精一种 regime,路由决定现在信谁。这也是你项目最有经济学直觉的地方。

**必读**:
- Hamilton(1989)regime 切换模型(马尔可夫切换的鼻祖,读摘要):https://www.jstor.org/stable/1912559
- 现代 ML 版:Temporal Routing Adaptor(TRA,ICLR 2023):https://arxiv.org/abs/2210.12153
